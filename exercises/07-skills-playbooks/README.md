# Exercise 07 - Skills And Playbooks

## Story

The lab repeats the same review and feature-planning patterns. You want a small project playbook that helps future agent sessions start faster.

## Goal

Create a reusable skill or playbook for this repository.

## Starting Point

- `skills/`
- Previous exercise prompts
- Project conventions from `README.md`

## Suggested Agent Prompt

```text
Create a small project playbook for this repo that explains how an agent should inspect, modify, test, and review changes in the Pokemon Card Agent Academy. Keep it practical and repo-specific.
```

## Steps

1. Ask the agent to identify repeated workflows.
2. Choose one playbook topic.
3. Create the playbook or skill file.
4. Use it on a small follow-up task.
5. Refine it based on what helped.

## Acceptance Criteria

- The playbook is specific to this repo.
- It contains actionable steps, not generic advice.
- You try it on a real small task.
- The result improves agent context or consistency.

## Reflection

- What should be encoded in a playbook?
- What should stay in normal conversation?
