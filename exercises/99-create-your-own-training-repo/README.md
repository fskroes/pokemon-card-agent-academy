# Exercise 99 - Create Your Own Training Repo

## Story

You have practiced agentic workflows in this Pokemon card repo. Now design a fresh training repo with your own domain and learning path.

## Goal

Create a new academy repo inspired by the structure of this one, not a direct copy of the domain.

## Starting Point

- This repository's `README.md`
- The `exercises/` folder structure
- Your notes from previous exercises

## Suggested Agent Prompt

```text
Help me design a new coding-agent training repo. Use the learning structure from this academy, but choose a fresh domain, service shape, exercise sequence, and step-by-step assignment docs. Start by brainstorming and ask clarifying questions only where necessary.
```

## Steps

1. Pick a domain that is concrete and easy to reason about.
2. Choose a small technical architecture.
3. Define the exercise sequence.
4. Write the folder-based assignment docs.
5. Build only enough baseline code to support the exercises.

## Acceptance Criteria

- The new repo has its own domain and README.
- Exercises live in folders, not separate branches.
- The learning path is step-by-step.
- At least one exercise involves debugging, testing, review, refactoring, repetitive change, CI, and plan-first implementation.

## Reflection

- What did you improve compared with this repo?
- Which exercise structure would help a beginner most?
